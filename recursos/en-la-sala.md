# En la sala

1. Instalar el CLI: `npm install -g @bnbagent/studio-cli`
2. Instalar las skills: `bag skills install`
3. En el editor, usar `/bnbagent-studio` y decir en una oración qué vende el agente.

El editor arma el proyecto. `bag dev` lo deja corriendo en la máquina. Recién ahí se habla de desplegar.
